# 隐私政策

Honyomi（包名 `fun.shuey.honyomi`）是一款开源的本地优先漫画 / 小说 / 视频阅读器。
本服务免费提供，按"现状"供用户使用。

本页面详细说明我们的个人信息收集、使用与披露政策。应用本体**不收集、不上传、不共享**任何个人信息：

- 无用户注册 / 登录体系；
- 无内嵌统计、分析或崩溃上报 SDK；
- 无广告 SDK；
- 不向开发者服务器发送任何数据（应用无自有后端服务器）。

## 信息收集与使用

为提供更好的体验，应用可能在以下用户**主动发起**的场景中与第三方网站或服务发生必要的网络交互：

| 场景 | 默认状态 | 涉及信息 | 用途与去向 |
| --- | --- | --- | --- |
| 本地书库 / 阅读进度 / 下载记录 / 偏好设置 | — | 仅存储于设备本地 | 不上传 |
| 打开在线书源（用户自行安装的扩展）浏览、阅读 | 关 | 浏览请求直达对应第三方站点 | 由该站点按其自身政策处理，应用不经手、不存储 |
| 连接追踪服务（同步阅读进度） | 自动同步默认开，需先登录对应服务 | 授权令牌或账号凭据、阅读进度 | 直达用户选择的追踪服务；凭据仅存于设备安全存储 |
| 视频弹幕（dandanplay） | 开（可随时关闭） | 正在播放的作品标题 | 发送至 api.dandanplay.net 用于匹配剧集并加载弹幕；不发送账号或设备标识 |
| 加密 DNS（DoH） | 关 | 域名解析请求 | 用户启用后发送至所选 DoH 服务商 |
| 听书（朗读） | — | 小说文本 | 调用系统端侧语音合成能力，在设备本地完成朗读 |
| 备份 / 恢复 | — | 书库、分类、阅读进度等 | 导出为文件保存于用户选择的位置；**不含**任何令牌、密码或 Cookie |
| 应用锁 | 关 | 系统锁屏凭据校验（口令、人脸或指纹） | 仅用于解锁应用。由系统弹窗完成，应用不采集生物特征 |

## 权限清单

应用声明的全部权限均为系统级（normal）授权，**未申请**任何需要用户弹窗授权（user_grant）的敏感权限：

| 权限 | 用途 |
| --- | --- |
| ohos.permission.INTERNET | 加载在线书源内容、连接用户选择的服务 |
| ohos.permission.GET_NETWORK_INFO | 获取网络状态以提示联网功能可用性 |
| ohos.permission.FILE_ACCESS_PERSIST | 记住用户授权导入的本地书库目录（免重复选目录） |
| ohos.permission.ACCESS_BIOMETRIC | 应用锁调用系统认证（口令、人脸或指纹） |
| ohos.permission.PRIVACY_WINDOW | 防截屏隐私保护（用户开启后生效） |
| ohos.permission.KEEP_BACKGROUND_RUNNING | 下载 / 听书 / BT 下载在后台持续运行 |

## 第三方服务

应用本身不集成收集个人信息的第三方 SDK。以下第三方服务均在用户主动操作时才会被使用，且各自受其隐私政策约束：

| 服务 | 触发方式 | 发送内容 | 存储位置 |
| --- | --- | --- | --- |
| 追踪服务（AniList、MyAnimeList、Kitsu、Shikimori、Bangumi、MangaUpdates、Hikka、Komga、Kavita、Suwayomi） | 用户主动登录 | 授权页、账号密码，或自建服务器地址与密钥；以及阅读进度 | 凭据仅存设备关键资产存储（TEE），不上传至任何其他方 |
| dandanplay 弹幕服务 | 视频播放且弹幕开启（默认开启，可关闭） | 作品标题（用于匹配剧集） | 弹幕内容仅内存缓存，不落盘 |
| 在线书源站点（用户安装的扩展所指向的网站） | 用户浏览 / 阅读该书源 | 浏览请求（直达该站点） | 由该站点自行处理 |
| DoH 服务商 | 用户开启加密 DNS（默认关闭） | 域名解析请求 | 不含用户身份信息 |

扩展（书源插件）以 `.honyomiplug` 包形式由用户主动安装，正式版仅允许通过 HTTPS 分发；应用不预置任何内容源，扩展行为由其各自的服务条款与隐私政策约束。

## 数据存储与安全

- 本地数据（书库、进度、设置）存储于应用沙箱，卸载即彻底删除；
- 追踪服务令牌 / 密码、扩展声明的敏感配置项存入系统关键资产存储服务（Asset Store，硬件安全环境 TEE）；
- 网络 Cookie 以 AES-256-GCM 加密存储，密钥保存于关键资产存储；
- 正式发行版启用代码混淆与裁剪，插件网络请求强制 HTTPS；
- 应用具备应用锁（系统锁屏凭据）和隐私界面（防截屏）等可选的本地防护。隐私界面默认只在无痕模式生效。

## 你的权利

- **查询 / 导出**：设置内可随时将书库数据备份导出；
- **删除**：卸载应用即删除全部本地数据（含安全存储中的令牌）；
- **撤回授权**：断开追踪服务即在设备上删除对应令牌；关闭弹幕、DoH、隐私功能即可停止对应数据发送；禁用 / 卸载扩展即停止与其站点的交互；
- **撤回同意**：卸载应用即视为撤回对本政策的同意。

## 未成年人保护

本应用不面向未成年人提供服务。由于在线内容来自用户自行安装的第三方书源，其中可能包含不适于未成年人的内容；应用默认隐藏标记为 NSFW 的书源与内容（可在设置中由用户自行开启），建议未成年人在监护人指导下使用。

## 政策更新

我们可能不定期更新本隐私政策。本政策更新后将在应用内「隐私政策」页与应用市场详情页同步发布。建议你定期查阅本页面以了解任何变更。
