# 首页介绍配图

把截图按下面的文件名放进本目录（`website/src/public/showcase/`）。首页标题旁边的那张图放在上一级的 `home/` 里。文件放好后刷新页面即可，缺图的位置会显示红色文件名和这张图应该拍什么。

中文首页和英文首页共用同一套图。

## 怎么截

- 使用应用的**浅色**界面、默认主题。官网深色模式下也用这些图。
- 手机图：竖屏全屏截图，PNG，宽度至少 1080 像素。不要套手机外框，不要加箭头或文字标注。
- 宽屏图：平板或 PC 窗口的横屏截图，PNG，宽度至少 1600 像素。
- 首页大图：同一张书架画面导出成 JPEG，宽度约 900–1400 像素。
- 这些图会公开在官网上。请使用你愿意公开展示的封面和正文。账号名、密钥、私人备注先退出登录或打码。追踪设置请在**未登录**时截，避免露出用户名。

## 必交

| 保存为 | 打开应用里的 | 画面里要有 |
| --- | --- | --- |
| `../home/phone.jpeg` | 书架 | 首页标题旁边的大图。网格封面即可，和下面的 `library.png` 可以是同一画面，这一份用 JPEG。 |
| `library.png` | 书架 | 网格封面。尽量带上分类页签，以及未读或已下载角标。底部能看出当前是「书架」页签。 |
| `updates.png` | 更新 | 新章节列表，能看到封面和章节名。尽量让「更新 / 时间表」切换入镜。 |
| `browse.png` | 浏览 | 已安装的扩展或书源列表，能看到名称和图标。有两三条比空列表更清楚。 |
| `detail.png` | 一部作品的详情 | 封面、标题、简介开头、章节列表。加入书架的按钮或已在书架的状态要在画面里。不要打开含有密钥的弹层。 |
| `reader.png` | 漫画阅读器 | 一页你愿意公开的漫画。优先把阅读菜单打开，让当前阅读模式（例如从右到左、条漫）入镜；菜单如果是半屏，上半部分仍要留着漫画。 |
| `novel.png` | 小说阅读器 | 已经排好版的一页正文。如果底部有朗读迷你条，留在画面里。 |
| `video.png` | 视频播放器 | 正在播放的画面和播控。有弹幕时让弹幕留在画面上。不要拍到登录令牌。 |
| `translate.png` | 打开了整章翻译的漫画页 | 原图上叠着译文。引擎还没配好时可以后补，页面会先显示占位。 |
| `downloads.png` | 更多 → 下载 | 队列里至少一条进行中或已完成的任务，能看到作品名和进度。 |
| `tracking.png` | 设置 → 追踪 | 服务列表，能认出 AniList、Bangumi 等名字。先退出登录再截。 |
| `stats.png` | 更多 → 统计 | 上方的概览数字，以及下方本周或本月的阅读时长图，尽量放在同一张图里。 |
| `wide.png` | 平板或 PC 上的书架 | 横屏。侧边导航要入镜。内容用书架；如果侧栏在设置页更清楚，用设置的左右双栏也可以。 |

一共 13 个文件：1 张 JPEG，12 张 PNG。

## 不用交的

分类、历史、备份、隐私、外观、迁移这些只在介绍文字里出现，不需要截图。文件名请和上表一致，多出来的图片不会显示。
