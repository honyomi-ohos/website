# Upcoming

The <navEn to="main_updates" /> header opens **Upcoming**. It lists chapters from the library that have not been published yet, grouped by date.

The header can filter that list by category as well.

## Airing calendar

The updates screen also has a **Calendar** segment next to the chapter list. It shows the Bangumi schedule from Monday through Sunday. Tap a weekday to switch days. Refreshing this segment reloads the calendar. Refreshing the chapter list checks the library.

## News about the app itself

New versions of the app are not posted on this screen. Update from Huawei AppGallery, and read the notes in the [changelogs](/en/changelogs/). Feature requests can go to [GitHub Issues](https://github.com/ShueyYuen/honyomi/issues). Search existing issues before opening a new one.
