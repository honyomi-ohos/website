# Smart updates

Frequently asked questions about how Honyomi checks the library for new chapters.

## How do update checks work?

The app visits each series’ source on that series’ own interval, then lists new chapters in <navEn to="main_updates" />. Change the interval on the series page.

The refresh control in the header checks the whole library immediately.

## Why is a series missing new chapters?

Possible reasons:

- The source is down, or the site layout changed and the extension needs an update;
- The source has not published a new chapter;
- The network failed;
- That series’ interval has not elapsed yet;
- <navEn to="library" /> has **Update on Wi-Fi only** or **Update while charging only** turned on, and the condition is not met.

Tap refresh in the <navEn to="main_updates" /> header to check again.

## Are new chapters downloaded automatically?

Not by default. **Download new chapters** in <navEn to="downloads" /> is off until you turn it on. After that, newly found chapters go to <navEn to="download-queue" />.

## How do I update the app itself?

There is no in-app updater. New builds come from Huawei AppGallery, and this site does not offer an install package. See the [download page](/en/download/) and the [changelogs](/en/changelogs/).
