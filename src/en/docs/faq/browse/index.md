# Browse

Frequently asked questions about the <navEn to="main_browse" /> tab in Honyomi.

## What is in the Browse tab?

The Browse tab collects all available sources, including:

- **Online sources**: provided by installed extensions, see [Extensions](/en/docs/faq/browse/extensions);
- **Local sources**: local manga, local novels, and local videos, see the [Local source guide](/en/docs/guides/local-source/).

When no extensions are installed, the Browse tab shows an installation guide.

## How do I search across all sources?

Use the search in <navEn to="main_browse" /> to search for series across all available sources at once.
