# Getting started

Essential information to help you get set up with **Honyomi**.

## Installation guide

### Downloading Honyomi

1. Visit our [download](/en/download/) page to get the latest version of **Honyomi**.
2. After the download is complete, open the package file.
3. Proceed with the installation process.

::: info System requirements
Honyomi requires HarmonyOS 6.1.0 or higher and runs on phones, tablets, and PCs.
:::

### Adding sources

Once **Honyomi** is installed on your device, you can add content in the following ways:

:::: tabs
== Local source
Read content stored locally on your device or external storage.

See the [Local source guide](/en/docs/guides/local-source/) for instructions.
== Extensions
Install community extensions (`.honyomiplug`) to add online sources:

* In the <navEn to="main_browse" /> tab, an installation guide is shown while no extensions are installed;
* Obtain a `.honyomiplug` package and install it in <navEn to="extensions" />.

::: danger Caution
Honyomi will not provide resources for any unofficial extensions. Beware that any third-party extensions will have full access to the app and may contain malware.
:::
== E-book files
When you open an EPUB / MOBI / AZW / AZW3 / PRC file from the file manager, choose to open it with Honyomi and the app will parse it and add it to your library.
::::

### Adding series to your library

After installing the desired extensions or setting up local sources, you will find the sources in the <navEn to="main_browse" /> tab.

Here's how you can add series to your library:

1. Select the source you'd like to browse.
1. You can use the **Popular**/**Latest** listings to browse, or you can search for the series name.
1. Once you've found the series that you want to add, tap on it for more details.
1. Press the "**Add to library**" button, and the series will be added to your Library, ready to be read!

## Additional setup

### Series search options

If you want to search for series across all your sources, you can use the global search feature:

1. Go to the <navEn to="main_browse" /> section.
1. Use the search to find series from all available sources at once.

### Trouble finding a specific series?

If you encounter difficulties while searching for a specific series, consider the following points:

* Double-check your spelling and try again, as some sources might use **romanized** titles instead of **English** ones.
  > Example: **Boku no Hero Academia** instead of **My Hero Academia**.

* Some sources may use different spellings or wordings for titles.
  > Example: **Bungo Stray Dogs** instead of **Bungou Stray Dogs**
