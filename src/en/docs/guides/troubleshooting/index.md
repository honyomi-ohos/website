# Troubleshooting

Troubleshooting guide for Honyomi.

When you run into a problem, we recommend checking in this order:

1. [Common issues](/en/docs/guides/troubleshooting/common-issues): most known problems are covered here;
1. [Diagnosis](/en/docs/guides/troubleshooting/diagnosis): if your problem isn't listed, follow the diagnosis flow to narrow it down.

## Reporting issues

If the problem persists, feel free to report it on [GitHub Issues](https://github.com/ShueyYuen/honyomi/issues). Please include:

- Steps to reproduce the issue;
- Device model and system version;
- Relevant screenshots or error messages.
