## Extension development

Honyomi extensions (source plugins) are distributed as `.honyomiplug` packages. If you want to write an extension for Honyomi, refer to `docs/plugin-interface.md` in the repository, which defines the extension manifest fields and runtime interface.

::: warning Caution
Honyomi will not provide resources for any unofficial extensions. Beware that any third-party extensions will have full access to the app and may contain malware.
:::

## Reporting issues

- Report issues on [GitHub Issues](https://github.com/ShueyYuen/honyomi/issues);
- Search existing issues before submitting to avoid duplicates;
- When reporting crashes or bugs, include reproduction steps and your device / system version.
