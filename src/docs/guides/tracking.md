# 追踪同步

把阅读进度写回追踪服务的指南。不登录也可以本地阅读。

## 支持的服务

一共 10 个，登录方式不同：

| 服务 | 登录 |
| --- | --- |
| AniList、MyAnimeList、Bangumi、Shikimori、Hikka | 应用内打开授权页 |
| Kitsu、MangaUpdates | 账号和密码 |
| Komga、Kavita、Suwayomi | 你自己的服务器地址，再加上该服务要求的账号或密钥 |

入口在 <nav to="tracking" />，也可以从作品详情页的追踪面板进入。

::: info 凭据存放
令牌和密码放在系统关键资产存储里，设置页不回显明文。
:::

## 自动同步

<nav to="tracking" /> 里的自动同步默认开启。章节被标为已读后，如果这部作品已经绑定了条目，应用会先刷新远端状态，再在本地章节号更靠后时把进度写回去。

关闭自动同步后，进度只留在本机，直到你在详情页里手动更新。

## 绑定一部作品

1. 打开书架中作品的详情页；
1. 打开 **追踪**；
1. 选择已经登录的服务，搜索并选中对应条目。

一部作品可以同时绑定多个服务。

## 退出登录

在 <nav to="tracking" /> 里对某个服务退出登录，设备上该服务的凭据会被清掉。只在详情页解除一部作品的绑定，不会退出整个账号。
