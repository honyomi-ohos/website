# 书源迁移

把书架里的作品从当前书源换到另一个书源，并带上已有的阅读进度。

## 什么时候用

原书源关站、章节不全，或你换了一个更合适的扩展时，用迁移把这部作品指到新书源，而不是删掉重加。

## 如何迁移

1. 从 <nav to="main_browse" /> 进入 <nav to="migrate" />；
1. 先选作品当前所在的书源；
1. 勾选该源下要迁移的作品，可以全选；
1. 选择目标书源，搜索并点中对应的作品；
1. 确认迁移。

完成后，书架记录和章节进度改到新书源。找不到对应作品时可以跳过这一部。

::: warning 章节不一定能对上
进度按章节号衔接。两个书源的分章方式不同时，对上的位置可能差一章，需要在新书源里看一眼再继续。
:::

## 迁移前

- 先按 [备份](/docs/guides/backups) 导出一份 JSON；
- 确认目标书源里这部作品的章节是齐的。
