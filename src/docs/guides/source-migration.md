# 书源迁移

在书源之间迁移作品的指南。

## 什么是书源迁移？

当你想把书架中的某部作品从一个书源迁移到另一个书源（例如原书源关站、换了更好的源）时，可以使用迁移功能，保留阅读进度与已下载内容。

## 如何迁移作品

1. 进入 <nav to="migrate" />；
1. 选择要迁移的作品；
1. 搜索并选择目标书源中的对应作品；
1. 确认迁移。

迁移完成后，作品的书架记录与阅读进度会切换到新书源。

::: warning 注意
迁移前后作品章节的对应关系取决于两个书源的章节命名，个别情况下需手动校正进度。
:::

## 迁移前的建议

- 先[备份数据](/docs/guides/backups)，以防万一；
- 确认目标书源中该作品的章节完整。
