# 快速上手

帮助你快速上手 **Honyomi** 的必备信息。

## 安装指南

### 下载 Honyomi

1. 访问本站 [下载](/download/) 页面获取最新版本的 **Honyomi**；
1. 下载完成后打开安装包；
1. 按提示完成安装。

::: info 系统要求
Honyomi 需要 HarmonyOS 6.1.0 或更高版本，支持手机 / 平板 / PC。
:::

### 添加内容源

安装完成后，你可以通过以下方式为 **Honyomi** 添加内容：

:::: tabs
== 本地源
阅读存储在设备本地或外置存储中的内容。

详见 [本地源指南](/docs/guides/local-source/)。
== 扩展
安装社区扩展（`.honyomiplug`）接入在线书源：

* 在 <nav to="main_browse" /> 页签中，未安装扩展时会显示扩展安装引导；
* 获取 `.honyomiplug` 插件包后，在 <nav to="extensions" /> 中安装。

::: danger 注意
Honyomi 不为任何第三方扩展或扩展仓库提供资源。任何第三方扩展都将拥有应用的完整访问能力，且可能包含恶意代码。
:::
== 电子书文件
在文件管理器中打开 EPUB / MOBI / AZW / AZW3 / PRC 文件时，选择用 Honyomi 打开，应用会自动解析并加入书架。
::::

### 将作品加入书架

安装所需的扩展或配置本地源后，你可以在 <nav to="main_browse" /> 页签中找到对应书源。

将作品加入书架的步骤：

1. 选择你想要浏览的书源；
1. 使用 **热门** / **最新** 列表浏览，或搜索作品名称；
1. 找到想要添加的作品后，点击进入详情页；
1. 点击 **加入书架** 按钮，作品即会加入 <nav to="main_library" />，随时可以开始阅读！

## 附加设置

### 跨书源搜索作品

如果你想同时在所有书源中搜索作品，可以使用全局搜索：

1. 进入 <nav to="main_browse" /> 页签；
1. 使用搜索功能，即可在所有可用书源中同时查找作品。

### 搜不到某部作品？

搜索特定作品遇到困难时，可以考虑以下几点：

* 仔细检查拼写后重试，部分书源可能使用**罗马音**标题而非中文或英文标题。
  > 例如：**Boku no Hero Academia** 而非 **我的英雄学院**。

* 部分书源对同一作品的译名或用词可能不同。
  > 例如：**文豪野犬** 而非 **文豪Stray Dogs**
