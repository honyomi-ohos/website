# 故障排查

Honyomi 问题排查指南。

遇到问题时，建议按以下顺序排查：

1. [常见问题](/docs/guides/troubleshooting/common-issues)：先对照已知问题列表，大部分常见问题都能在此找到答案；
1. [问题诊断](/docs/guides/troubleshooting/diagnosis)：如果常见问题列表中没有你要找的问题，可以按诊断流程进一步定位。

## 反馈问题

如果排查后仍未解决，欢迎在 [GitHub Issues](https://github.com/ShueyYuen/honyomi/issues) 提交反馈，请附上：

- 问题的复现步骤；
- 设备型号与系统版本；
- 相关的截图或错误信息。
