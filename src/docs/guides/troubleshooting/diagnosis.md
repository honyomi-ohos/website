# 问题诊断

Honyomi 问题诊断流程。

## 基本排查

遇到问题时，先依次确认：

1. **系统版本**：HarmonyOS 6.1.0 及以上；
2. **应用版本**：使用最新版本（可在 [下载页](/download/) 核对）；
3. **网络**：联网功能（在线书源、追踪、弹幕）依赖网络连接；
4. **重启**：重启应用，多数偶发问题可通过重启解决。

## 按功能定位

| 功能 | 依赖 | 排查方向 |
| --- | --- | --- |
| 在线书源 | 网络 + 扩展 | 换一个书源测试；确认扩展版本 |
| 本地源 | 文件夹授权 + 同步 | 重新同步；检查目录结构 |
| 电子书 | 文件本身 | 换一个文件测试 |
| 听书 | 系统 TTS 引擎 | 检查系统文字转语音设置 |
| 弹幕 | 网络 + dandanplay 服务 | 换一个热门作品测试 |
| 追踪同步 | 网络 + 授权令牌 | 断开后重新授权 |
| 下载 | 存储空间 + 网络 | 检查剩余空间与下载设置 |

## 收集信息

如果问题仍然存在，提交反馈时请提供：

- 复现步骤（越详细越好）；
- 设备型号与系统版本；
- 应用版本号（<nav to="about" /> 中查看）；
- 问题截图或错误提示原文。

## 提交反馈

在 [GitHub Issues](https://github.com/ShueyYuen/honyomi/issues) 提交问题。提交前请先搜索已有 issue，避免重复。
