# 常见问题

Honyomi 运行中的常见问题与解决方法。

## 应用无法安装

* 确认系统版本为 HarmonyOS 6.1.0 及以上；
* 确认安装包完整（重新下载后再试）；
* 若覆盖安装失败，可先卸载旧版本（注意先[备份数据](/docs/guides/backups)）。

## 书源无法加载内容

* 检查网络连接是否正常；
* 书源站点可能暂时不可用，稍后重试；
* 源站结构变更时，需要等待对应扩展更新。

## 本地源看不到内容

* 确认已在 <nav to="main_browse" /> 选择正确的本地源并完成同步；
* 确认目录结构符合[本地源目录组织格式](/docs/guides/local-source/)；
* 从文件夹添加 / 删除内容后，需重新执行同步才会生效。

## 电子书打开失败

* 确认文件格式受支持（EPUB / MOBI / AZW / AZW3 / PRC）；
* 文件可能已损坏，尝试用其他阅读器打开验证。

## 听书没有声音

* 检查设备媒体音量；
* 确认系统已安装可用的语音合成引擎；
* 部分设备需在系统设置中启用文字转语音（TTS）功能。

## 弹幕不显示

* 确认弹幕开关已开启（播放器内可切换）；
* 弹幕依赖 dandanplay 服务匹配剧集，冷门作品可能没有弹幕数据；
* 检查网络连接。

## 追踪服务同步失败

* 确认已在对应官网完成授权登录；
* 令牌可能已过期，尝试断开后重新连接；
* 检查网络连接。

## 下载中断或失败

* 检查存储空间是否充足；
* 开启了仅 Wi-Fi 下载时，需连接 Wi-Fi；
* BT 下载依赖按需下载的 BT 组件，确认组件下载完成。

## 阅读器卡顿

* 尝试关闭双页模式或裁剪白边等额外处理；
* 超大图片章节在低端设备上可能加载较慢，属正常现象；
* 重启应用后再试。
