# 阅读器设置

**Honyomi** 漫画阅读器、小说阅读器与视频播放器的设置说明。

## 漫画阅读器

从书架打开漫画进入阅读器：

- **翻页模式**：左右翻页（点击 / 滑动）或连续垂直滚动；
- **显示设置**：双页模式、裁剪白边、亮度滤镜、阅读方向；
- **底部工具栏**：章节列表、页面跳转、设置面板；
- 阅读进度与阅读位置自动记忆。

全局默认值可在 <nav to="reader" /> 设置中调整。

## 小说阅读器与听书

- **排版**：字号、行距、字体、页边距、主题与背景色；
- **听书**：端侧语音合成朗读，支持语速调节、后台连续播放与通知栏控制；
- 章节导航与进度记忆同漫画阅读器。

听书朗读在设备本地完成，不联网。

## 视频播放器

打开视频章节进入播放器：

- **手势**：双击左右区域快退 / 快进，上下滑动调节音量 / 亮度；
- **控制**：倍速、画质、剧集列表、锁定；
- **弹幕**：默认开启，可随时关闭。

全局默认值可在 <nav to="player" /> 设置中调整：

- 弹幕开关；
- 弹幕字号、不透明度、显示区域、滚动速度；
- 倍速与自动连播。
