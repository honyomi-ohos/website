# 阅读

关于 Honyomi 漫画阅读器、小说阅读器与视频播放器的常见问题与解答。

## 漫画阅读器支持哪些模式？

- **翻页模式**：左右翻页（点击 / 滑动）；
- **连续垂直滚动**：适合条漫（webtoon）；
- **双页模式**、**裁剪白边**、**亮度滤镜**、**阅读方向**等显示设置可在阅读器内调整。

详见 [阅读器设置](/docs/guides/reader-settings)。

## 小说可以听书吗？

可以。Honyomi 支持端侧语音合成听书：

- 支持语速调节；
- 支持后台连续播放与通知栏控制；
- 朗读在设备本地完成，不联网。

## 视频播放器有哪些手势？

- 双击左右区域：快退 / 快进；
- 上下滑动：调节音量 / 亮度；
- 支持倍速、画质、剧集列表与画面锁定。

## 弹幕是如何工作的？

视频弹幕默认开启，可随时关闭。开启时应用会把正在播放的作品标题发送至 dandanplay 服务（api.dandanplay.net）用于匹配剧集并加载弹幕；不发送账号或设备标识。弹幕字号、不透明度、显示区域、滚动速度可在 <nav to="player" /> 设置中调整。

## 阅读进度会自动记录吗？

会。应用自动记忆每部作品的阅读进度与阅读位置，并在下次打开时恢复。

## 阅读进度可以同步到追踪服务吗？

可以，支持 AniList、MyAnimeList、Bangumi、Kitsu、Shikimori、MangaUpdates、MangaBaka、Hikka 共 8 个追踪服务。详见 [追踪同步指南](/docs/guides/tracking)。
