# 智能更新

关于 Honyomi 作品更新检查的常见问题与解答。

## 更新检查是如何工作的？

应用会按计划的间隔访问你书架内作品所在的书源，检查是否有新章节，并将结果显示在 <nav to="main_updates" /> 页签。

## 为什么有些作品没有显示新章节？

可能的原因包括：

- 该书源站点暂时不可用或结构变更（需要更新对应扩展）；
- 作品在源站尚未发布新章节；
- 网络连接异常。

可尝试下拉 <nav to="main_updates" /> 页签手动刷新。

## 新章节会自动下载吗？

不会默认自动下载。下载需在作品详情页或 <nav to="download-queue" /> 中手动发起。

## 如何检查应用自身的更新？

应用内暂不提供自动更新。请关注本站 [下载页](/download/) 或 [GitHub Releases](https://github.com/ShueyYuen/honyomi/releases) 获取新版本。
