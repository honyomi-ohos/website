# 智能更新

关于 Honyomi 书架更新检查的常见问题与解答。

## 更新检查是如何工作的？

应用按每部作品自己的间隔访问它所在的书源，检查有没有新章节，并把结果放进 <nav to="main_updates" />。间隔在作品详情页里改。

顶栏的刷新会立刻检查整架书架。

## 为什么有些作品没有显示新章节？

可能的原因包括：

- 书源暂时不可用，或站点结构变了，需要更新对应扩展；
- 源站还没有发布新章节；
- 网络异常；
- 这本书的检查间隔还没到；
- <nav to="library" /> 打开了 **仅 Wi-Fi 时更新** 或 **仅充电时更新**，而当前不满足条件。

可以点 <nav to="main_updates" /> 顶栏的刷新再查一次。

## 新章节会自动下载吗？

默认不会。<nav to="downloads" /> 里的 **下载新章节** 默认关闭。打开之后，检查到的新章节会进入 <nav to="download-queue" />。

## 如何检查应用自身的更新？

应用内没有单独的更新器。新版本由华为应用市场推送，本站不提供安装包。说明见 [下载页](/download/) 和 [更新日志](/changelogs/)。
