# 通用

关于 **Honyomi** 的常见问题与解答。

## Honyomi 是什么？

Honyomi（包名 `fun.shuey.honyomi`）是一款基于 HarmonyOS 的本地优先多格式阅读器，支持漫画、小说、电子书与视频的统一管理与阅读，可通过安装社区扩展（`.honyomiplug`）接入在线书源。

## 支持哪些设备与系统版本？

支持 HarmonyOS 6.1.0 及以上系统的手机 / 平板 / PC。

## Honyomi 收集我的个人信息吗？

不收集。应用本体不集成任何统计、分析、崩溃上报或广告 SDK，无用户注册体系，也不向开发者服务器发送任何数据。详情请参阅[隐私政策](/privacy/)。

## 支持哪些内容格式？

:::: tabs
== 电子书
EPUB / MOBI / AZW / AZW3 / PRC
== 漫画
本地漫画目录（文件夹）、ZIP / CBZ 压缩包
== 视频
MP4 / MKV / WebM / MOV / M4V
== 在线内容
通过社区扩展（`.honyomiplug`）接入在线书源，漫画、小说、视频均可支持。
::::

## 如何获取帮助？

- 查看本站的 [指南](/docs/guides/getting-started) 与 [常见问题](/docs/faq/general)；
- 在 [GitHub Issues](https://github.com/ShueyYuen/honyomi/issues) 提问。

## 我可以在 Honyomi 中找到哪些内容？

Honyomi 不预置、不分发任何内容。在线内容由你自行安装的第三方扩展提供，应用本体仅为阅读器。
