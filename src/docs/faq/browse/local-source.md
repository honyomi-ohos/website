# 本地源

关于 Honyomi 本地源的常见问题与解答。

## 本地源支持哪些内容？

:::: tabs
== 本地漫画
图片目录（jpg / jpeg / png / webp / gif / bmp / avif）与 ZIP / CBZ 压缩包。
== 本地小说
txt 文本章节。
== 本地视频
mp4 / mkv / webm / mov / m4v 视频文件。
::::

## 如何使用本地源？

1. 在 <nav to="main_browse" /> 选择「本地漫画」「本地小说」或「本地视频」；
1. 首次使用时点击 **选择文件夹**，从系统文件选择器中选定一个文件夹并授权；
1. 点击 **同步**，应用会扫描文件夹并识别作品与章节；
1. 此后应用会一直记住该文件夹，重启后自动恢复访问权限。

完整的目录组织格式请参阅 [本地源指南](/docs/guides/local-source/)。

## 为什么同步会占用额外存储空间？

由于系统限制，普通应用不能直接遍历用户目录。同步时会把所选文件夹整树复制进应用沙箱再扫描，因此内容约占等量存储空间。建议所选文件夹专用于本地源。

## 从文件夹删除内容后为什么不生效？

从源文件夹删除内容后，需要重新执行同步才会生效。

## 电子书（EPUB 等）也走本地源吗？

不需要。在文件管理器中打开 EPUB / MOBI / AZW / AZW3 / PRC 文件时，选择用 Honyomi 打开，应用会自动解析并加入书架。
