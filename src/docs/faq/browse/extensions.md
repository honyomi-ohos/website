# 扩展

关于 Honyomi 扩展（`.honyomiplug`）的常见问题与解答。

## 什么是扩展？

扩展是接入在线内容的插件。安装后，它提供的书源出现在 <nav to="main_browse" />。

Honyomi 不预置内容源，也不为第三方扩展或仓库提供资源。

## 如何安装扩展？

两种方式都在 <nav to="extensions" />：

1. **插件仓库**：添加仓库地址，刷新后从列表安装。已安装的扩展可以在这里检查并更新；
1. **本地文件**：从文件选择器安装 `.honyomiplug` 或 `.zip`。

未安装任何扩展时，浏览页会显示安装引导。

## 什么是 NSFW 扩展？

标记为 NSFW 的书源默认不显示。在 <nav to="browse" /> 打开 **显示 NSFW 源** 后才会出现在浏览和更新里。

## 可以只让某一个扩展不记历史吗？

可以。打开扩展详情，打开该插件的隐身开关。浏览这个插件的书源时，不写阅读历史，也不计阅读时长。全局无痕在 <nav to="incognito-mode" />。

## 安装扩展有什么风险？

::: danger 注意
第三方扩展拥有应用的完整访问能力，也可能包含恶意代码。Honyomi 不审核这些扩展。只添加你信任的仓库，只安装你信任的包。
:::
