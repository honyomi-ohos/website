# 浏览

关于 Honyomi <nav to="main_browse" /> 页签的常见问题与解答。

## 浏览页签有什么？

浏览页签汇集了所有可用的书源，包括：

- **在线书源**：由已安装的扩展提供，详见 [扩展](/docs/faq/browse/extensions)；
- **本地书源**：本地漫画、本地小说、本地视频，详见 [本地源](/docs/guides/local-source/)。

未安装任何扩展时，浏览页会显示扩展安装引导。

## 如何跨书源搜索作品？

在 <nav to="main_browse" /> 使用搜索功能，即可在所有可用书源中同时搜索作品。
