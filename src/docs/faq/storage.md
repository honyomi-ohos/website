# 存储

关于 Honyomi 数据存储的常见问题与解答。

## 我的数据保存在哪里？

- **本地数据**（书架、进度、设置）存储于应用沙箱，卸载即彻底删除；
- **追踪服务令牌 / 密码、扩展敏感配置**：存入系统关键资产存储服务（Asset Store，硬件安全环境 TEE）；
- **网络 Cookie**：AES-256-GCM 加密存储，密钥保存于关键资产存储。

## 卸载应用会删除我的数据吗？

会。卸载即删除全部本地数据（含安全存储中的令牌）。如需保留书库数据，请先[备份](/docs/guides/backups)。

## 如何备份数据？

进入 <nav to="settings" /> → **备份**，可将书架、分类、阅读进度、下载记录导出为本地备份文件。详见 [备份指南](/docs/guides/backups)。

备份文件**不含**任何令牌、密码或 Cookie。

## 如何恢复数据？

在 <nav to="settings" /> → **备份** 中选择备份文件导入，即可恢复书库数据。
