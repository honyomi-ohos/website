# 设置

关于 Honyomi <nav to="settings" /> 各设置组的常见问题与解答。

## 设置页有哪些设置组？

| 设置组 | 内容 |
| --- | --- |
| <nav to="reader" /> | 阅读器主题、翻页方式、裁边、滤镜等 |
| <nav to="player" /> | 倍速、自动连播、弹幕参数 |
| <nav to="browse" /> | NSFW 源显示开关 |
| <nav to="downloads" /> | 下载路径、仅 Wi-Fi 下载 |
| <nav to="appearance" /> | 深色模式、动态取色、图标样式 |
| <nav to="advanced" /> | 自定义 User-Agent、加密 DNS（DoH）开关与提供商 |
| <nav to="security-and-privacy" /> | 应用锁（生物识别）、锁定时机、防截屏隐私窗口、隐藏通知内容 |
| <nav to="local" /> | 本地目录管理 |
| 关于 | 版本信息、开源许可、隐私政策、帮助 |

## 如何开启深色模式？

在 <nav to="appearance" /> 中选择深色模式，或跟随系统。

## 什么是加密 DNS（DoH）？

DoH（DNS over HTTPS）通过 HTTPS 加密域名解析请求，可避免 DNS 查询被明文窃听或劫持。默认关闭，可在 <nav to="advanced" /> 中开启并选择提供商。

## 如何防止别人看到我的阅读内容？

- 在 <nav to="security-and-privacy" /> 中开启 **应用锁**（生物识别）；
- 开启 **防截屏隐私窗口**（截屏 / 录屏时内容不显示）；
- 开启 **隐藏通知内容**；
- 使用无痕模式（<nav to="incognito-mode" />）阅读时不记录历史。
